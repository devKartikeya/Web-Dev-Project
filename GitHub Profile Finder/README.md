📌 GitHub Profile Finder
A sleek and responsive web app that lets you quickly search for any GitHub user by their username. Built with HTML, CSS, and JavaScript, this project focuses on clean design, smooth interactions, and a modern UI.

🚀 Features
🔍 Search by Username — instantly navigate to any GitHub profile.

🎨 Modern UI — glassmorphism card layout, gradients, hover animations.

📱 Responsive Design — works seamlessly across desktop and mobile.

⚡ Quick Access — supports both button click and pressing Enter.

✨ Interactive Styling — glowing inputs, animated hover effects, and bold typography.

⚙️ Installation & Usage
Clone the repository:

bash
git clone https://github.com/devKartikeya/web-dev-project.git

bash
cd github-profile-finder
Open index.html in your browser.

🎯 How It Works
Enter a GitHub username in the search bar.

Click Search or press Enter.

You’ll be redirected to the user’s GitHub profile page instantly.

📱 Responsive Layout
On larger screens: GitHub and Profile Finder are displayed in bold, oversized letters alongside the search box.

On mobile: the layout stacks vertically for easy access.
